# Third-Party Attribution

The OPV-DB publication-facing release is a literature-mined secondary
compilation. During internal construction, the workflow also used and compared
against external OPV data resources and modelling datasets. The public CSV
exports intentionally omit unstable internal source labels, so the files should
not be interpreted as providing row-level third-party provenance.

## Upstream Work This Release Derives From

Qiu, J. *OPV-DB: a literature-mined organic photovoltaic device performance
database* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20841543
Licensed CC BY 4.0.

This release is a derivative of that database, extended with an independently
literature-mined device-record collection. See the "Relationship to the
original OPV-DB" section of `README.md` for the list of changes.

## Related OPV Data Resource

Li, Y.-F. *Training dataset for predicting PCE of organic solar cells* [Data
set]. Zenodo (2025). https://doi.org/10.5281/zenodo.16784519

Users should cite the OPV-DB release for this deposited package. When directly
combining OPV-DB with the Li 2025 Zenodo dataset or other external curated
resources, cite those resources separately according to their own licenses and
metadata.
